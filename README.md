# 📊 Investment Portfolio Performance Analysis

---

## 📈 Overview

This repository presents an interactive **Microsoft Power BI dashboard** developed to analyze the performance of a diversified investment portfolio.

The project evaluates investment allocation, current portfolio value, company-wise returns, profitability, and overall portfolio performance through interactive dashboards and visual analytics.

The analysis combines **Excel-based portfolio data, Power BI visualizations, and DAX measures** to transform raw investment data into meaningful financial insights.

---

## 💡 Project Objective

The primary objective of this project is to analyze portfolio performance and provide a clear view of:

- Total amount invested
- Current portfolio value
- Overall portfolio return
- Company-wise investment performance
- Company-wise profitability
- Top-performing stocks
- Profit contribution by company
- Investment vs. current value
- Investment vs. return relationships

The dashboard is designed to support data-driven understanding of portfolio performance and investment allocation.
