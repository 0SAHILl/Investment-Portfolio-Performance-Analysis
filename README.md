## 📊 Dashboard

### Portfolio Overview

![Portfolio Overview](DASHBOARD%20IMAGES/PAGE%201.png)

The overview dashboard provides a high-level summary of the portfolio, including:

- Total Amount Invested
- Current Portfolio Value
- Number of Companies
- Overall Portfolio Return
- Company-wise Return
- Top Performing Stock
- Profit Contribution by Company

### Portfolio Performance Insights

![Portfolio Performance Insights](DASHBOARD%20IMAGES/PAGE%202.png)

The insights page provides deeper analysis through:

- Investment vs. Current Value by Company
- Investment vs. Return Analysis
- Company and Sector Filters
- Interactive Portfolio Exploration
