# 📊 Investment Portfolio Performance Analysis

An interactive **Power BI portfolio analysis dashboard** developed to evaluate investment performance across a diversified stock portfolio.

The project analyzes investment value, current portfolio value, stock-wise returns, profitability, and company-level performance to generate actionable financial insights.

---

## 🎯 Project Objective

The objective of this project is to analyze portfolio performance and identify:

- Overall portfolio return
- Investment vs. current portfolio value
- Best-performing stocks
- Company-wise returns
- Profit contribution by company
- Investment distribution across companies
- Key performance differences between investments

---

---

## 🔍 Key Insights

- **Siemens** emerged as the top-performing stock with a **7.12% return**.
- The portfolio generated an overall return of approximately **2.36%**.
- The portfolio consists of investments across **7 companies**.
- The dashboard enables comparison between the amount invested and current market value.
- Company-wise profit contribution highlights which investments contribute most to portfolio profitability.
